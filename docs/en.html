What's inside

Every layer is built from scratch, with no third-party crates. Everything claimed here is covered by tests and honestly documented — limitations included.

⚙️Lisp core

Interpreter with cons pairs in a GC heap, tracing GC with a background thread, closures, macros, tables, a SIMD tokenizer (AVX-512/SSE2/scalar with runtime dispatch).

🚀JIT numeric kernels

Copy-and-patch compilation of lambdas to x86-64 machine code: arithmetic, comparisons, if/cond/let/let*, min/max/abs/sqrt/floor. Up to 234× on a mixed kernel, bit-exact parity with the interpreter, transparent deoptimization.

🎱Physics with honest rolling

NGS solver: accumulated impulses, Coulomb friction at the contact point with an angular coupling, restitution from central approach. Sliding → rolling follows theory exactly, no energy pumping on slopes, bitwise determinism.

🦴Skeleton + particles

Bone hierarchy → world matrices → gpu3d-batch-mat (a 4×4 matrix per instance). A CPU pool of 4096 particles with LCG burst scatter — deterministic without rand.

🧩ECS in the core

Slots + generations (zombie handles are impossible), O(1) access, bulk queries ecs-each/ecs-col in slot order. The Lisp-level ecs.lisp stays a DSL.

📦Asset manager

A named registry with types and refcounts: put!/ref!/release!/gc!, type validation on retrieval, slot reuse after explicit collection.

🎨Rendering: software + wgpu

A software pipeline: T&L, z-buffer, vertex colors, tiled textures, fog, an alpha pass with painter's sort, instance batching. A wgpu backend behind the same HAL facade — Lisp never changes.

🎬Post-processing (stage 19)

gpu3d-post: bloom (excess over threshold → ¼ downsample → box blur), exposure with a soft shoulder (midtones untouched), vignette, deterministic grain (hashed, no rand). ~0.6 ms at 400×300.

🌤️Atmosphere (stage 20)

A gradient sky dome, a sun disk with a bloom halo, drifting clouds (procedural texture, radial silhouette), blob shadows under bodies, water glitter — all from Lisp on top of the existing natives.

🛠️Unity-like editor

Scene tree, gizmo manipulators, inspector, scene saving to a Lisp file, hot reload without a restart. AI Ready: an MCP server lets an agent drive the engine.

🔊Chiptune audio

Zero-dep synthesis: oscillators, ADSR envelopes, music tracks — and WebAudio in the sandbox driven by physics events.

Honest limitations

A selling site that lies about "everything works" isn't a selling site. So here is what is NOT done — in the same font as the achievements.

Rolling resistance is not modeled — a perfect sphere rolls forever: friction only damps slipping.

SIMD tokenizer: 1.07× instead of the 3× criterion — analysis and a fix plan (symbol interning, pshufb) in docs/benchmark.md.

Per-vertex skinning is not done — the skeleton animates instances (a matrix per bone), not mesh vertices.

Clouds are billboards with a procedural texture, not volumetric: the texel alpha channel is ignored by the sampler (the pass blend is a constant), so the silhouette is a radial brightness falloff.

The atmosphere costs ~27% fps (24 → 17.5): water glitter is a Lisp loop over 625 vertices; vectorizing it with native ALU ops is the next optimization candidate.

The wgpu backend is offscreen + readback; there is no windowed swapchain.

The full list — LIMITATIONS.md, updated every stage.
