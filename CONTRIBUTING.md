# Contributing

Язык проекта — русский (документация) и Rust (код). PR приветствуются.

## Принципы репозитория

1. **Ноль зависимостей в дефолтной сборке.** Любая новая зависимость — только за
   opt-in фичей (как `wgpu`). CI проверяет это (`cargo tree`).
2. **HAL не знает игровых понятий.** Окно/растр/ввод/память/время/PNG/MCP — да;
   draw-sprite/physics-step — нет, это Lisp-уровень.
3. **Честность.** Никаких непроверенных бенчмарков: каждое число — из реального
   запуска с указанием окружения. Ограничения фиксируются в LIMITATIONS.md.
4. **Совместимость.** Поддерживаем rustc 1.83+: не используем std-API стабильнее
   этой версии без cfg-гейта (см. `build.rs` / `has_avx512`).

## Процесс

```bash
cargo build --release
cargo test
bash scripts/smoke.sh
cargo fmt --check && cargo clippy --all-targets -- -D warnings
```

Перед PR убедитесь, что всё зелёное локально; CI повторяет те же шаги
(+ проверка feature `wgpu`). Один PR — одна тема; коммиты — conventional
(`feat:`, `fix:`, `docs:`, `test:`, `ci:`).
