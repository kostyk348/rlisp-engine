# CHANGELOG

Формат — Keep a Changelog; версии семантические.

## [Unreleased] — 0.4.0

### Добавлено (этап 1 роадмапа: «HAL — тонкий и быстрый»)

- **wgpu-бэкенд за фасадом HAL** (`src/gpu.rs`, фича `wgpu`, wgpu 0.20 / MSRV
  rustc 1.75): offscreen-рендер RGBA8 → WGSL-шейдер (solid/текстурный квады,
  nearest, discard alpha=0) → copy-to-buffer → map-read → композит в
  `Hal::fb` по альфе-покрытию. Все пути вывода (PNG / ASCII / веб-редактор /
  MCP-скриншоты) работают без изменений. Дефолтная сборка остаётся
  **с нулём зависимостей** (проверяется в CI через `cargo tree`).
- **`--wgpu`** — выбор GPU-бэкенда на старте; без адаптера (CI/VM/headless)
  или при сборке без фичи — предупреждение и честный откат на программный
  растр (все скрипты продолжают работать). В баннере движка теперь видно
  активный бэкенд: «рендер: программный растр | wgpu: …».
- **Менеджер GPU-ресурсов** (`GpuResources`): книга хэндлов текстур с
  подсчётом created/freed/live/bytes, поколения при перезагрузке,
  инвалидация при hot-reload (текстуры, на которые ссылаются
  persistent-значения, сохраняются). Тест-критерий этапа: стресс
  «100 create/reload циклов без роста памяти» — зелёный.
- **Профилирование кадра**: `--bench` замеряет синтетический 2D-кадр
  320×240 (clear + 120 fill-rect + 12 blit + 4 blit-tex + present) на
  программном растре и, с `--wgpu`, на GPU — с разбивкой submit / readback;
  отдельно тот же кадр через интерпретатор (накладные расходы Lisp). Без
  адаптера печатает «wgpu-адаптер недоступен» и выходит с кодом 0.
- **CI** (`.github/workflows/ci.yml`): fmt-check, clippy `-D warnings`,
  build+test с проверкой нуля зависимостей, `cargo check/test --features
  wgpu`, smoke.sh. Триггеры: push в master и pull_request.
- **Документация**: `docs/roadmap.md` (7 этапов, критериями и статусами),
  `docs/architecture.md` (слои, карта модулей, дизайн wgpu-бэкенда),
  `docs/benchmark.md` (реальные замеры с указанием окружения).

### Изменено

- `build.rs`: модуль `simd::avx512` включается по cfg `has_avx512`
  (rustc ≥ 1.89, где `_mm512_*` стабилизированы); на 1.83 сборка снова
  зелёная, диспетчер честно выбирает AVX2/SSE. Ранее репозиторий не
  собирался stable-компиляторами младше 1.89.
- `cargo clippy --all-targets -- -D warnings` доведён до чистоты
  (исправлено 24 предупреждения), применён `cargo fmt`.

### Исправлено

- Утечка текстур при hot-reload (v0.3): старые записи реестра оставались до
  рестарта (~64 КБ/текстуру за reload) — теперь освобождаются менеджером
  ресурсов; README «Честные отличия» обновлён.
- `gpu-blit-tex` по освобождённой текстуре паниковал (usize underflow) —
  теперь возвращает Lisp-ошибку «текстура освобождена», как 3D-нативы.

### Честные ограничения этапа 1

- wgpu закрывает 2D-растр; 3D-конвейер (T&L, z-буфер, батчи) остаётся
  программным (перенос на GPU — этап 5 роадмапа).
- Критерий «`--wgpu` кратно быстрее» требует GPU-железа; замеры песочницы
  без адаптера честно помечены в `docs/benchmark.md`, числа не выдуманы.
